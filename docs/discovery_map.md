# Idleon Automation — Discovery Surface Map

This repository is in a **discovery phase**. It has probed a handful of corners of a large game — six minigame screen-bots (two-to-three of them statistically mature, several still scaffold), a launcher with card/book recommenders, and a Haxe save decoder that can read the *entire* save tree but exposes typed accessors for only five top-level keys. Nothing here is "finished."

This document maps every catalogued Legends of Idleon system against what the tooling currently does, to guide what to build next. Coverage is deliberately strict:

- ✅ **Covered** — a working bot or launcher feature directly targets the system.
- 🟡 **Partial** — some save data is decoded/surfaced, or a thin feature touches it, but no end-to-end automation/recommendation.
- ⬜ **Blank** — no bot, no accessor, no feature. (The save decoder *can* parse it; "Blank" means nothing reads it into a helper.)

_Generated by the `discovery-surface-map` workflow on 2026-06-20. A living map — statuses drift as the tooling and the game evolve; re-run to refresh._

## High-value discovery targets

Ranked by leverage — account impact, follow-on tooling unlocked, and lift (lower when the save is already partly decoded or an existing pattern can be copied).

1. ~~**Stamps (decode + recommender)**~~ — ✅ **Done** (Stamps tab + `stamp_recommender`). Sizing-up corrected the axis: gold clamps trivial, so ranking is by *material* cost + ownership, not gold.
2. **Alchemy — Bubbles (decode + recommender)** — One of the largest permanent-bonus systems in the game; reading cauldron/bubble levels enables a "next bubble to upgrade" advisor reusing the recommender skeleton. Big payoff, pure save-side work.
3. **Finish the Mining bot** — Already scaffolded with detectors, a policy module, and a DB; it's a partial that's close. Surviving past early obstacles converts a 🟡 to ✅ and completes the shared-pool minigame trio (chopping/catching/mining) the launcher already gates.
4. **Finish the Catching bot (phase-lock)** — Detectors and a fitted dynamics controller exist; the single open problem is multi-bob phase-locking. Highest-completion-per-effort among the minigames since the hard CV work is done.
5. **Complete `read_max_book_level` boosters (#95)** — Five named-but-unread sources (Salt Lick, Atom Collider, Sailing, Summoning, Achievement) already have comment placeholders; decoding them tightens an existing shipped feature and forces first-time decodes of those five systems — a cheap wedge into W3-W6 save structures.
6. **Merit Shops + Tasks/Dailies (full decode)** — Only one task index is read today; the rest drives merit-shop unlocks across every world. Decoding the task/merit arrays feeds a high-value "unspent merits / next unlock" advisor and unblocks any system priced in merits.
7. **Obols (decode + placement advisor)** — Account/family stat slots with fusion mechanics map cleanly onto a recommender ("which obol to fuse/place next"); self-contained save subsystem, no bot required.
8. **Equipment / Inventory decode** — Reading `EquipOrder`/`ItemQTY`/storage is foundational plumbing many other advisors (smithing targets, upgrade checks, sell/dump helpers) would depend on; low glamour, high follow-on unlock.
9. **Post Office (decode + order advisor)** — Self-contained per-character box system with clear "deliver this order next" logic; another low-lift recommender-pattern candidate.
10. **The Rift (full progression decode)** — Already read at `Rift[0]`; decoding the rest surfaces milestone gating that affects card cap and account bonuses, extending an accessor that already exists.
